Developer API

RESTful Vision API

Programmatically integrate deep learning image recognition, OpenCV diagnostics, and Grad-CAM heatmaps into any application.

POST /api/classify — Primary classification with diagnostics & telemetry
Payload Options:
  • Multipart: image (binary file)
  • JSON: {"image": "base64..."}
  • JSON: {"imageUrl": "https://..."}
  • Query params: model, filter, gradcam=true
cURL Example: 
curl -X POST http://127.0.0.1:5000/api/classify \
  -F "image=@photo.jpg" \
  -F "model=mobilenet_v3_large" \
  -F "gradcam=true"
Python Example: 
import requests

url = "http://127.0.0.1:5000/api/classify"
with open("dog.jpg", "rb") as f:
    res = requests.post(
        url,
        files={"image": f},
        data={"model": "mobilenet_v3_large", "gradcam": "true"}
    )
data = res.json()
print("Top:", data["top_prediction"]["label"])
print("Confidence:", data["top_prediction"]["confidence_pct"])
print("Latency:", data["telemetry"]["inference_time_ms"], "ms")
POST /api/gradcam — Computes neural attention heatmap overlay 
curl -X POST http://127.0.0.1:5000/api/gradcam \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/jpeg;base64,...", "model": "mobilenet_v3_large"}'
GET /api/models — Catalog of supported models and runtime specs 
curl http://127.0.0.1:5000/api/models
GET /api/health — Server health, hardware accelerator and framework version 
curl http://127.0.0.1:5000/api/health
