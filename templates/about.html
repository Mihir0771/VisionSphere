System Architecture

Engineering & Vision Pipeline

A deep dive into the computer vision algorithms, convolutional neural network backbones, explainable AI mechanics, and real-time streaming pipeline powering VisionSphere.

Convolutional Neural Networks & Backbones

VisionSphere leverages pretrained vision models trained on the ImageNet-1k dataset (1.4 million images across 1,000 object categories). Supported architectures include:

  • MobileNetV3: Hard-swish activations and squeeze-and-excitation blocks for ultra-low latency mobile/web inference.
  • ResNet50: 50-layer deep residual network with bottleneck skip connections solving vanishing gradients.
  • EfficientNet-B0: Uniform compound scaling across network depth, width, and input resolution.

Explainable AI (Grad-CAM)

Gradient-weighted Class Activation Mapping (Grad-CAM) computes the gradients of the target class score with respect to the feature activation maps of the final convolutional layer:

L_GradCAM^c = ReLU( Σ_k α_k^c * A^k )

The resulting activation map is upsampled with bilinear interpolation and colorized using OpenCV's JET colormap, highlighting the exact visual patterns the network used to make its decision.

OpenCV Visual Diagnostics

Prior to model inference, images undergo automated computer vision diagnostics:

  • Laplacian Variance: Computes the 2nd spatial derivative to detect blurry or unfocused captures.
  • CLAHE: Contrast Limited Adaptive Histogram Equalization in LAB color space prevents over-amplification of noise.
  • Contour Saliency: Gaussian smoothing and Otsu binarization locate primary foreground objects.

Software Architecture & Tech Stack

Designed for high performance, modularity, and clean separation of concerns:

  • Backend: Flask 3.1 & Python 3.14
  • Inference Engine: TensorFlow 2.22 / Keras 3 with oneDNN CPU vectorization
  • Image Processing: OpenCV 5.0 (cv2) & NumPy
  • Frontend: Ultra Luxury Glassmorphism, Ambient Mesh Gradients, Canvas API, Web Speech TTS
